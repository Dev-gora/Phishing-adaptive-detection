Model Architectures

Random Forest

Type Bagged decision trees
Splitting Best feature split (Gini impurity)
Max Features sqrt(auto-selected)
Ensemble Size 300 trees (configurable)

Random Forest averages multiple decision trees trained on random subsets of data and features. Reduces overfitting compared to single trees and provides built-in feature importance via mean decrease in Gini.

XGBoost

Type Gradient-boosted trees
Learning Strategy Gradient boosting with histogram approximation
Regularization
Objective Binary logistic loss (logloss)

XGBoost builds trees sequentially, each new tree correcting residuals of previous ones. Handles missing values natively and provides L1/L2 regularization to prevent overfitting. Fast histogram-based approximation for training.

LightGBM

Type Leaf-wise gradient boosting
Efficiency
Max Leaves 31 leaves per tree (configurable)
Objective Binary logistic loss (logloss)

LightGBM grows trees leaf-wise instead of level-wise, making it significantly faster and more accurate than level-wise growers like XGBoost. Uses Gradient-based One-Side Sampling (GOSS) and Exclusive Feature Bundling (EFB) for efficiency.

k-Nearest Neighbors (KNN)

Type Instance-based learning
Distance Minkowski with p=2 (Euclidean)
Preprocessing StandardScaler (mandatory)
k-value 5 neighbors (tunable)

KNN classifies based on majority vote of nearest training instances. Requires feature scaling since it's distance-based. Lazy learner - no training phase, all computation happens at prediction time. Sensitive to curse of dimensionality with many features.

Adaptive Feature Selection

Adaptive Rule

The adaptive selection rule finds the smallest feature subset k such that:
F1(k) ≥ F1(full) - ε
where ε ∈ {0.01, 0.02, 0.05} and patience=3 (3 consecutive sizes must satisfy)
