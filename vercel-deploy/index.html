Paper Overview

This research focuses on developing a lightweight and explainable machine learning framework for phishing website detection. The study compares eight feature-selection techniques and four machine learning models, investigating whether explainability-driven feature selection can provide a practical balance between accuracy, interpretability, and computational efficiency.

  • Eight feature-selection methods compared: SHAP, LIME, Permutation Importance, Mutual Information, RFE, RF Gini, SLA-FS, and adaptive selection
  • Four models evaluated: Random Forest, XGBoost, KNN, and LightGBM
  • Adaptive feature-selection strategy: F1(k) ≥ F1(full) - ε with ε = 0.01, 0.02, 0.05
  • Dataset: Hannousse & Yahiouche (2021), Mendeley Data V3, 11,430 samples, 87 features
  • Key finding: Adaptive rule parks k on the tolerance boundary; SLA-FS provides the best efficiency-strength trade-off
