# Figure attribution and provenance

No figure is reproduced from another publication. Figures 1–11 are original diagrams drawn for this paper; Figures 12–27 are outputs of the experimental pipeline described in Sections 10 and 14. The dataset is CC BY 4.0 and is attributed to Hannousse and Yahiouche (Mendeley Data V3, doi:10.17632/c2gw7fy2j4.3). The reference paper (doi:10.1016/j.dsm.2024.08.004) is cited, not redistributed.

| Figure | File | Caption |
|---|---|---|
| 1 | `figures/fig25_class_distribution.png` | Class distribution of the benchmark as published and after the removal of duplicate feature vectors. The published file is exactly balanced; cleaning removes 174 duplicates, all but one of which are legitimate pages, leaving a 49.2% phishing rate. |
| 2 | `figures/fig26_target_correlation.png` | Univariate correlation of each feature with the label, computed on the training split only. External-service features and hyperlink counts show the strongest association; several URL-lexical counts are close to uncorrelated. |
| 3 | `figures/fig27_correlation_structure.png` | Correlation structure of the 81 modelled features on the training split. The block structure reflects the three feature families and explains why attribution methods distribute credit among near-duplicate attributes. |
| 4 | `figures/fig01_system_architecture.png` | Overall system architecture. Representation, ranking and decision are separate stages. The ranking layer produces nine complete orderings from one fitted surrogate; the decision layer consumes a ranking and a tolerance and returns a subset, a classifier and an explanation. |
| 5 | `figures/fig02_preprocessing_pipeline.png` | Preprocessing pipeline. Steps four to six are applied to the full frame before splitting; imputation is fitted inside the model pipeline on training folds only. Every count in the diagram is recorded in the preprocessing report. |
| 6 | `figures/fig03_feature_selection_workflow.png` | Feature-selection workflow. Six established selectors read one fitted surrogate and emit complete orderings; the fusion operator consumes the SHAP and LIME orderings and emits three more, giving nine rankings that can be truncated at any k. |
| 7 | `figures/fig04_shap_method.png` | SHAP methodology. Marginal contributions are computed for each coalition, weighted by coalition size, and averaged to give the Shapley value; summing the values with the base value reconstructs the prediction exactly. |
| 8 | `figures/fig05_lime_method.png` | LIME methodology. Perturbations are sampled around the instance, weighted by proximity, and used to fit a sparse weighted ridge regression whose coefficients form the explanation; averaging their magnitude over many instances yields a global score. |
| 9 | `figures/fig06_slafs_architecture.png` | SLA-FS architecture with three fusion operators. The intersection operator is a reproduction of the published rule; the rank-average and score-blend operators are our operationalisation and are labelled as such in every results table. |
| 10 | `figures/fig07_adaptive_selection.png` | Adaptive feature-selection workflow, including the patience window and the explicit fallback path. The selected subset is frozen before the test block is read. |
| 11 | `figures/fig08_evaluation_protocol.png` | Evaluation protocol. The test block is never seen by a selector, a sweep point, a tolerance choice or a hyper-parameter search; the two permitted reads are shown. |
| 12 | `figures/fig20_f1_models_methods.png` | Test F1 by classifier and selection method at the default tolerance. The full-feature bar is the reference; every reduced bar is measured on the same locked test block. |
| 13 | `figures/fig23_roc_curves.png` | ROC curves on the test block. The three ensembles are nearly superimposed; the instance-based learner separates from them at low false-positive rates. |
| 14 | `figures/fig24_confusion_matrices.png` | Confusion matrices on the test block. Errors are approximately balanced between the two classes for the ensembles; KNN is markedly more conservative about the legitimate class. |
| 15 | `figures/fig09_importance_by_method.png` | Normalised feature importance of the fifteen leading features under each selector. The agreement at the head of the ranking is visible as the dominance of the first bar in every panel. |
| 16 | `figures/fig10_rank_heatmap.png` | Rank assigned to each of the leading features by each selector. Vertical bands indicate features on which all selectors agree; horizontal bands indicate a selector that orders the feature set differently from the rest. |
| 17 | `figures/fig14_rank_agreement.png` | Spearman rank agreement matrix. Permutation importance is the clear outlier; SHAP, RFE and Gini importance form a tight cluster, which is the basis for the cost argument in Section 18. |
| 18 | `figures/fig15_stability_curve.png` | Stability as a function of k. LIME is stable at the head and unstable beyond k = 10; permutation importance is never stable; SHAP improves monotonically with k. |
| 19 | `figures/fig16_selection_cost.png` | Selection time by selector on a logarithmic scale. The explanation-based methods are two to three orders of magnitude more expensive than the filter and the embedded measure. |
| 20 | `figures/fig17_adaptive_curve_shap.png` | Validation F1 as a function of subset size for the SHAP ranking with a Random Forest. The tolerance band around the full-feature score is marked; the accepted k is the smallest prefix that stays inside the band for three consecutive sizes. |
| 21 | `figures/fig18_adaptive_summary.png` | Reduction and accuracy change for every tolerance and selector. The frontier flattens beyond roughly twenty features, which is the empirical basis for the compact subsets reported in Table 15. |
| 22 | `figures/fig11_shap_beeswarm.png` | SHAP summary over the test block. Each row is a feature, each point an instance, position is the attribution and colour is the standardised feature value, scaled per feature. |
| 23 | `figures/fig12_shap_instance.png` | SHAP attribution for an individual test instance. Positive values push the prediction towards phishing, negative values towards legitimate, and the sum with the base value equals the model output. |
| 24 | `figures/fig13_lime_instance.png` | LIME explanation for the same instance. The local linear surrogate agrees with SHAP on the leading features and differs in the middle of the list, consistent with the 0.894 rank correlation between the two global rankings. |
| 25 | `figures/fig22_model_cost.png` | Training and inference cost by classifier. Inference cost is close to flat in the number of features for tree ensembles and strongly decreasing for the instance-based learner. |
| 26 | `figures/fig21_features_vs_performance.png` | Performance as a function of the number of retained features. The curve rises steeply to roughly twenty features and then flattens, which bounds the useful range of the adaptive sweep. |
| 27 | `figures/fig19_reduction_cost.png` | Reduction against inference cost for every configuration. Configurations in the lower left achieve large reductions without a cost increase; those in the upper left pay for compactness in accuracy without a latency gain. |
